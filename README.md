## 👋 About Me

> **"화면에서 입력한 값이 API와 데이터베이스를 거쳐 다음 업무까지 정확히 이어지는지 끝까지 확인합니다."**

- 인테리어 사업을 운영하며 고객 상담에서 정한 사양이 견적과 발주까지 빠짐없이 전달되어야 현장의 재확인을 줄일 수 있다는 점을 체감했습니다.
- 개발 프로젝트에서도 **요구사항 확인 → API·데이터 흐름 구현 → 오류 조건 재현 및 수정 → 배포 후 로그·실행 상태 확인**까지 이어지는 방식으로 일합니다.
- 개인 온프레미스 환경(**Proxmox VE 3노드·Ansible·K3s·Argo CD**)을 직접 구축해 애플리케이션 코드가 실제 컨테이너 환경에서 기동되는 과정을 검증해 왔습니다.
